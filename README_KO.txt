AQUA WARS 온라인 서버 및 플레이어 참가 업데이트

구성
- index.html: 모바일 게임 화면, 보스전, 왕관/오로라 상점, 온라인 로비
- server.js: Express + Socket.IO 온라인 서버
- package.json: Node 실행 패키지
- render.yaml: Render 배포 설정

온라인 참가 기능
- 방장은 공개 대기 방을 만들고 보스 연습을 하며 다른 참가자를 기다립니다.
- 공개 방은 열린 방 목록에 표시되며, 비공개 방은 초대 코드로 입장합니다.
- 방장 외 일반 플레이어도 '플레이어로 입장' 버튼 또는 방 코드로 참가할 수 있습니다.
- 두 번째 참가자가 들어오면 방장과 참가자 모두 선택한 온라인 스테이지로 자동 이동합니다.
- 경기가 이미 시작된 뒤에도 7명 정원에 도달하기 전이면 플레이어가 중간 참가할 수 있습니다.
- 늦게 입장한 플레이어에게 빈 시작 위치를 배정하고, 참가자별 위치를 다른 플레이어에게 전송합니다.
- 방장 포함 최대 7명까지 참가할 수 있습니다.

Render 배포 설정
- Root Directory: 저장소 루트
- Build Command: npm install
- Start Command: npm start
- Health Check Path: /health

다운로드한 HTML로 접속할 때
- 온라인 로비의 '온라인 서버 주소'에 Render 공개 주소를 입력하고 '주소 적용'을 누르세요.
- 기본 주소는 https://aqua-wars-online.onrender.com 입니다. Render에서 다른 주소를 발급했다면 실제 주소로 바꾸세요.

온라인 동기화 범위
현재 서버는 방과 참가자 목록, 경기 시작, 참가자별 시작 위치 및 플레이어 위치를 동기화합니다. 영토 점령, 공격 판정, 체력, AI 진행은 아직 각 브라우저에서 별도로 계산합니다. 따라서 완전한 서버 권한형 실시간 대전은 추가 개발이 필요합니다.
